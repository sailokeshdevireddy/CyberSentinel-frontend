# CyberSentinel Frontend

This is the React frontend for CyberSentinel, built with Vite.

## Structure

*   `src/assets/`: Static assets (images, icons)
*   `src/components/`: Reusable UI and dashboard components
*   `src/data/`: Mock data for development
*   `src/layouts/`: Layout-level components (navigation, sidebar)
*   `src/pages/`: Main page components
*   `src/routes/`: Routing logic
*   `src/services/`: Frontend services that currently use local mock data (these will connect to the Java backend in the future)

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run the Frontend (Development)
```bash
npm run dev
```

### Build the Frontend (Production)
```bash
npm run build
```
